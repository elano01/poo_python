# Game Pokémon RPG

Um projeto de estudo em Python para praticar programação orientada a objetos por meio da construção de um jogo de RPG inspirado no universo Pokémon.

O projeto acompanha as aulas do Projeto 2 da Academia da SOLYD. A proposta é desenvolver o jogo gradualmente, aplicando os conceitos aprendidos e registrando a evolução neste repositório.

## Status

🚧 **Em início de desenvolvimento.** O código do jogo ainda será construído ao longo das aulas. As funcionalidades abaixo são objetivos de estudo, não recursos já disponíveis.

## Objetivos de aprendizado

- Criar classes, objetos e métodos em Python.
- Usar `__str__`, argumentos opcionais e herança.
- Modelar Pokémon e pessoas, incluindo suas interações.
- Utilizar a biblioteca `random` em encontros e batalhas.
- Desenvolver o fluxo do jogo e explorar o salvamento de progresso.

## Etapas previstas
